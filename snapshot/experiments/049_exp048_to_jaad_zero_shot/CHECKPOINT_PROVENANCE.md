# Exp049 Checkpoint Provenance

Exp049 performs inference only with the 18 completed Exp048 checkpoints for
Variants A--F and seeds 42, 43, and 44. Each checkpoint is accepted only when:

- its Exp048 training completion marker identifies the same variant and seed;
- its SHA-256 equals the artifact hash stored in that completion marker;
- its checkpoint metadata identifies the same variant and seed;
- its state dictionary loads strictly into the frozen Exp048 architecture;
- its instantiated parameter count equals the frozen variant count.

The machine-readable `metrics/checkpoint_provenance.json` was generated by the
final pre-inference audit and records the exact checkpoint path, checkpoint
SHA-256, marker path, marker SHA-256, and parameter count for all 18 models.
`AUDIT_COMPLETE` binds that record and every other pre-inference artifact by
SHA-256 before JAAD test labels or probabilities may be accessed.

No Exp048 checkpoint is selected, altered, fine-tuned, or recalibrated for
JAAD. The fixed decision threshold remains 0.5.

Independent post-run verification confirmed that every prediction marker's
pre-inference and post-inference model-state SHA-256 values are identical.
